# AGENTS.md

## Code Review Rules

Ревью ведётся по правилам из `.ai/review-prompt.md` и проектным стандартам из `.ai/main-prompt.md`, `.ai/backend-prompt.md`, `.ai/frontend-prompt.md`. Перед ревью прочитай эти файлы.

Кратко, чтобы ничего не потерялось:

- Ищи только реальные проблемы: деньги и точность (`float` вместо `Decimal`, округление, идемпотентность), гонки и транзакции в БД, таймауты и ретраи внешних вызовов, безопасность и утечки данных в логах. Без вкусовщины и придирок.
- Тон всегда вежливый и конструктивный. К каждому замечанию — конкретное предложение исправления.
- Комментарии пиши на русском.
- Формат протокола обязателен, его читают автоматические агенты. Первая строка каждого ревью или общего комментария:
  `[codex-review] round: N verdict: CHANGES_REQUESTED` или `[codex-review] round: N verdict: APPROVED`.
  N — число твоих предыдущих ревью с этим маркером на PR плюс один.
- Если критических (🚨) и надёжностных (⚠️) проблем нет, обязательно оставь комментарий с `verdict: APPROVED`. Не молчи и не ищи замечаний ради замечаний.
- Полное описание протокола — в `.ai/review-prompt.md`, раздел «Протокол взаимодействия с Claude-агентами».
